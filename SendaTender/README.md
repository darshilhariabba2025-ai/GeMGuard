# ProcureSure — SIH 2026 PS 26100 prototype

Open `index.html` in any modern browser. No server, account, or installation is required.

The demo persists bidder decisions in browser local storage. Use **Reset demo data** in the Officer Portal to restore its starting data.

AI/OCR extraction and government registry integrations are deliberately labelled simulated/mock: this is a safe, offline prototype, not a connection to government systems.
